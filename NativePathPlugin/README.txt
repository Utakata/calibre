Native Path Plugin for Calibre
==============================

このプラグインは、Calibreが書籍ファイルを保存する際のファイル名・フォルダ名を、
ローマ字変換（ASCII）ではなく、元の日本語などの文字のまま保存するように変更します。

インストール方法
----------------
1. Calibreの「設定 (Preferences)」を開きます。
2. 「高度な設定」セクションにある「プラグイン (Plugins)」をクリックします。
3. 「ファイルからプラグインを読み込む (Load plugin from file)」をクリックします。
4. この `NativePathPlugin.zip` を選択します。
5. セキュリティ警告が表示された場合は「はい (Yes)」をクリックします。
6. Calibreを再起動します。

使い方
------
### 新規に追加する書籍
プラグインをインストールして再起動した後に追加した書籍は、自動的に日本語のファイル名で保存されます。

### 既存の書籍（すでにローマ字になっているもの）
既存の書籍のフォルダ名・ファイル名を日本語に変更するには、以下の手順を行います：

1. ライブラリ画面で、変更したい書籍を選択します（複数選択可）。
2. ツールバーに追加された「パスの正規化 (Standardize Paths)」ボタンをクリックします。
   ※ ボタンが見当たらない場合は、ツールバーの右端の「>>」メニューの中にあるか、
      「設定」>「ツールバーとメニュー」からメインツールバーに追加してください。
3. これにより、Calibre内でファイルパスの再計算が行われ、フォルダ名とファイル名が日本語に変更されます。

注意点
------
* このプラグインはCalibreの内部ロジック（`construct_path_name`）を書き換えます。
* Calibreのバージョンアップにより動作しなくなる可能性があります。
* Windows環境での使用を想定していますが、ファイル名に使えない文字（`:` `?` `/` など）は自動的に `_` に置換されます。
